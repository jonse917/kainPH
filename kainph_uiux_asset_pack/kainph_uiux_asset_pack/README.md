## Important limitations
These cropped images are reference extracts from a composite concept image, not original source photography or vector logo files. Some crops may contain UI artifacts or text and should not be treated as production-ready product photography. For production, replace the reference crops with licensed, clean individual images and create a proper vector logo (SVG) or transparent PNG.

The visual mockup is a design reference, not a functional application. Prices, merchant names, sales numbers, and receipt details shown in it are illustrative only. Do not encode them as real business rules or production seed data.
